# Turkish Legal Question Answering with Small Language Models

This repository contains the implementation and experimental results of the **CSE4078 Spring 2026 Term Project**.

The project evaluates two small open-source instruction-tuned language models on Turkish legal question answering and fine-tunes the better-performing model using **Supervised Fine-Tuning with QLoRA**.

The complete workflow includes:

* Dataset loading and preprocessing
* Baseline inference on two language models
* ROUGE and BERTScore evaluation
* Model selection
* QLoRA fine-tuning
* Validation during training
* Final evaluation on the unseen official test split
* Storage of trained LoRA adapter weights and experiment metadata

---

## Project Objective

The main objective is to investigate whether parameter-efficient fine-tuning can improve the Turkish legal question-answering ability of a small language model with 0.3B–4B parameters.

Two models were evaluated:

1. [Qwen/qwen3b-Instruct](https://huggingface.co/Qwen/qwen3b-Instruct)
2. [amd/Instella-3B-Instruct](https://huggingface.co/amd/Instella-3B-Instruct)

Both models were evaluated on the same 1,500-example test split. qwen3b-Instruct achieved substantially better baseline results and was therefore selected for fine-tuning.

---

## Dataset

The project uses the following Hugging Face dataset:

[Renicames/turkish-law-chatbot](https://huggingface.co/datasets/Renicames/turkish-law-chatbot)

| Split                   | Number of examples | Usage                                    |
| ----------------------- | -----------------: | ---------------------------------------- |
| Official training split |             13,354 | Training and validation only             |
| Training subset         |             12,018 | QLoRA fine-tuning                        |
| Validation subset       |              1,336 | Validation and best-checkpoint selection |
| Official test split     |              1,500 | Baseline and final evaluation only       |

The validation split was created from the official training split using a fixed random seed of `42`.

The official test split was not used during:

* training,
* deduplication,
* validation,
* checkpoint selection,
* or hyperparameter configuration.

Exact duplicate removal was applied before the train-validation split. No exact duplicates were found, so all 13,354 training examples were retained.

## Models

### Baseline Model 1

```text
Qwen/qwen3b-Instruct
```

Qwen is a multilingual instruction-tuned causal language model with approximately 3 billion parameters.

### Baseline Model 2

```text
amd/Instella-3B-Instruct
```

Instella is an instruction-tuned causal language model with approximately 3 billion parameters.

### Fine-Tuned Model

The selected Qwen model was fine-tuned using:

* Supervised Fine-Tuning
* PEFT LoRA adapters
* 4-bit QLoRA quantization
* NF4 quantization
* Double quantization
* Gradient checkpointing
* An 8-bit paged AdamW optimizer

Only the LoRA adapter parameters were trained.

## Prompt Format

The same Turkish legal-assistant prompt structure was used during training and evaluation:

```text
Sistem: Sen bir Türk hukuk asistanısın. Kullanıcının hukuki sorularını doğru ve eksiksiz bir şekilde yanıtla.

Soru: <question>

Bağlam: <optional context>

Cevap: <answer>
```

The answer is omitted during inference and generated by the model.

## Generation Configuration

All three reported test evaluations used the same generation configuration:

| Setting             | Value                   |
| ------------------- | ----------------------- |
| Test samples        | 1,500                   |
| Maximum new tokens  | 128                     |
| Sampling            | Disabled                |
| Decoding method     | Greedy decoding         |
| `do_sample`         | `False`                 |
| Temperature         | Not applied             |
| Prompt format       | Identical across models |
| Quantized inference | 4-bit where enabled     |

Using deterministic greedy decoding ensures that repeated evaluations produce consistent outputs under the same software and hardware environment.

## Evaluation Metrics

Two automatic evaluation methods were used.

### ROUGE

ROUGE measures lexical overlap between the generated answer and reference answer.

The following variants are reported:

* ROUGE-1
* ROUGE-2
* ROUGE-L
* ROUGE-Lsum

### BERTScore

BERTScore measures contextual semantic similarity between the generated and reference answers.

The following encoder was used consistently for every model:

```text
bert-base-multilingual-cased
```

Reported BERTScore metrics:

* Precision
* Recall
* F1

## Experimental Results

All results below were calculated using the same official 1,500-example test split.

### Complete Results

| Model                | Setting    |    ROUGE-1 |    ROUGE-2 |    ROUGE-L | ROUGE-Lsum | BERTScore Precision | BERTScore Recall | BERTScore F1 |
| -------------------- | ---------- | ---------: | ---------: | ---------: | ---------: | ------------------: | ---------------: | -----------: |
| Instella-3B-Instruct | Baseline   |     0.0260 |     0.0004 |     0.0229 |     0.0233 |              0.5136 |           0.5403 |       0.5249 |
| qwen3b-Instruct  | Baseline   |     0.1886 |     0.0834 |     0.1552 |     0.1544 |              0.6230 |           0.6612 |       0.6404 |
| qwen3b-Instruct  | Fine-tuned | **0.2851** | **0.1579** | **0.2496** | **0.2500** |          **0.7095** |       **0.7189** |   **0.7130** |

### Improvement After Fine-Tuning

Relative improvement of fine-tuned Qwen compared with baseline Qwen:

| Metric       | Baseline | Fine-tuned | Relative improvement |
| ------------ | -------: | ---------: | -------------------: |
| ROUGE-1      |   0.1886 |     0.2851 |          **+51.18%** |
| ROUGE-2      |   0.0834 |     0.1579 |          **+89.39%** |
| ROUGE-L      |   0.1552 |     0.2496 |          **+60.78%** |
| ROUGE-Lsum   |   0.1544 |     0.2500 |          **+61.96%** |
| BERTScore F1 |   0.6404 |     0.7130 |          **+11.35%** |

The results show that QLoRA fine-tuning substantially improved both lexical overlap and semantic similarity.

## Model Selection

qwen3b-Instruct was selected for fine-tuning because it outperformed Instella-3B-Instruct on every baseline metric.

In particular:

* Qwen baseline ROUGE-1 was approximately 7.3 times higher.
* Qwen baseline ROUGE-2 was substantially higher.
* Qwen baseline BERTScore F1 was approximately 0.1155 points higher.
* Qwen generated more relevant and coherent Turkish answers during qualitative inspection.

Therefore, allocating the available training resources to Qwen was the most appropriate experimental decision.

## Limitations

The project has several limitations:

1. ROUGE primarily measures lexical overlap and does not directly verify legal correctness.
2. BERTScore measures semantic similarity but may still assign high scores to legally incorrect statements.
3. No professional legal expert manually evaluated all 1,500 generated answers.
4. Only one random seed and one primary fine-tuning configuration were evaluated.
5. No extensive hyperparameter search was performed.
6. The maximum training sequence length was limited to 256 tokens because of hardware constraints.
7. Deduplication detects exact duplicates but not semantically equivalent examples.
8. The models may generate hallucinated, outdated, incomplete or incorrect legal information.

The results should therefore be interpreted as an academic comparison of language-model adaptation methods rather than as proof of legal reliability.

## Conclusion

Among the two evaluated baseline models, qwen3b-Instruct achieved substantially better Turkish legal question-answering performance than Instella-3B-Instruct.

QLoRA fine-tuning further improved Qwen across every reported metric. The largest relative improvement was observed in ROUGE-2, while BERTScore F1 also increased from `0.6404` to `0.7130`.

These results demonstrate that parameter-efficient fine-tuning can meaningfully improve a small multilingual language model for domain-specific Turkish legal question answering, even under limited GPU-memory constraints.
